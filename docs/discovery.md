# 发现与资源安装

发现页支持 Modrinth、CurseForge 的整合包、模组、资源包和光影。游戏本体下载及本地整合包导入位于工具栏。

## 浏览

- 搜索词、游戏版本、加载器、分类和排序组合查询。筛选控件同时显示用途、图标和当前选项，窄窗口下自动换行。游戏版本选择器支持搜索，也可直接输入快照或旧版本号。
- 提供卡片与列表两种视图。游戏版本和加载器使用低对比度标签，多个加载器分别展示。Fabric、Forge、NeoForge、Quilt、OptiFine 使用自绘单色矢量标识，Legacy Fabric 复用布卷标识；标签与菜单的标识一致。游戏版本列表只显示明确支持的版本，不用连续区间暗示兼容性。
- 每个来源和资源类型分别记住筛选、页码和滚动位置。当前应用会话内缓存最近 60 页搜索结果；刷新按钮重新请求当前页。
- 切换页面或打开资源后返回不会主动重新请求已缓存内容。请求失败保留上次成功的数据，旧响应不会覆盖新的筛选请求。
- 项目详情包含 Markdown/HTML 简介、图库、项目相关链接、版本和逐文件更新日志。描述使用系统 WebKit 呈现，外链在默认浏览器打开。
- 版本按所支持的最新 Minecraft 版本分组，行内仍显示完整适配范围的摘要；一个文件只出现一次。文件名搜索和发布类型筛选作用于已经载入的文件，可继续“载入更多”。

## 安装

- 选择文件后，可安装到已有实例、新建兼容实例，或使用系统保存面板单独下载。
- 从实例的内容管理进入发现页时，会自动带入资源类型、游戏版本、加载器和目标实例，并显示实例名称和配置；切换资源来源时保留这个筛选上下文。版本页也可以主动选择“按实例筛选”，无需依赖含糊的“当前实例”按钮。
- 已有实例按版本和加载器进行兼容性判断，可显示不兼容实例；正在使用的实例不可写入。
- 新建实例会先安装游戏和加载器，再安装资源；整合包继续使用现有的清单预览和导入流程。
- 安装前递归解析必需依赖，区分安装、更新、重新启用及已安装。兼容的已有依赖优先保留；指定版本依赖仍严格遵循作者要求。
- 依赖页展示必需、可选、内置、不兼容及工具关系，可跳转到项目并使用导航返回。安装清单中的前置依赖也可以直接打开。
- 既有文件经过校验才标记为“已安装”。重新启用使用现有文件的临时副本，不必重新下载；下载后统一通过原有内容事务写入。
- 安装预览保存资源清单快照，提交时拒绝覆盖预览后发生的资源变化；保留原有校验、同名文件冲突保护及回滚机制。
- CurseForge 禁止第三方分发的文件仍由用户在网站下载，再在界面选择并校验，不绕过作者的分发设置。
- 仅下载文件会校验当前文件，但不自动下载其依赖。发现页底部显示当前任务进度，可打开下载日志查看完整记录。

## 边界

搜索结果和依赖关系依赖平台元数据。未受管理的本地文件无法可靠映射到平台项目，界面会提示；没有加入中文模组名称翻译数据库。缓存只在应用会话内保留。截图和说明中的静态图片可展示，第三方脚本、表单和嵌入式网页不会执行。

富文本解析使用固定版本的 Swift Markdown 0.8.0，因此构建工具链最低为 Swift 6.2；macOS 最低版本保持 14。

## 手动验收建议

构建由 Codex 完成；以下功能与界面验证留给维护者：

1. 两个来源分别翻到第二页及后续页，离开发现页后返回，切换来源/类型后返回原页。
2. 连续输入、清空搜索，快速切换游戏版本/加载器，断网后重试，检查结果与页码一致。
3. 打开包含图片、表格、代码块的简介，查看截图、外部链接和更新日志；切换深浅外观及窄窗口。
4. 从依赖关系跳转至前置项目并返回；从带必需依赖的模组打开依赖检查。
5. 覆盖缺失依赖、已安装依赖、已禁用依赖、指定依赖版本、不兼容依赖和预览后修改本地文件。
6. 从没有兼容实例的资源新建实例并安装；已有实例安装；仅保存文件及取消保存；整合包导入。
7. 使用 CurseForge API Key 检查分类、筛选、版本分页及受限分发文件的手动下载与校验。
