# Java distribution artwork

These marks identify installed third-party software. They are not SF Symbols
and do not imply endorsement. The original artwork retains its shapes, aspect
ratio and colors; a consistent display area provides alignment with the UI.

Retrieved 2026-09-14:

- `homebrew.svg`: https://brew.sh/assets/img/homebrew.svg — Homebrew's apple and beer mug, used on https://brew.sh/.
- `graalvm.svg`: https://www.graalvm.org/resources/img/brand-guidelines/downloads/GraalVM-icon.svg — official GraalVM icon, from https://www.graalvm.org/graalvm-brand-guidelines/.
- `zulu.svg`: https://www.azul.com/wp-content/uploads/Prime-Illustration-10.svg — the artwork labeled “Azul Zulu downloads of OpenJDK” on https://www.azul.com/downloads/.
- `azul.svg`: https://www.azul.com/wp-content/themes/azul/assets/img/logo.svg — Azul's company wordmark; used when the vendor is known but the Zulu distribution is not identified.
- `microsoft.svg`: a vector transcription of the four-square symbol in https://uhf.microsoft.com/images/microsoft/RE1Mu3b.png; see https://blogs.microsoft.com/blog/2012/08/23/microsoft-unveils-a-new-look/.

Homebrew, Azul/Zulu, GraalVM, and Microsoft artwork and trademarks belong to
their respective owners. Unknown distributions use the generic Java category
symbol and are never assigned an unrelated brand mark.
